## Materials:
- Cardboard
- Paint
- Glue (I used hot glue bc strong and quick to adhere)
- Optional
	- Duct tape (for model accuracy)
	- Alternative method to attach top to bottom
		- I used 3D printed bolts so I can remove the top for storage/transport

## Tools:
- Knife (I recommend a box cutter or utility knife of some sort)
- Scissors
- Straight Edge (good for marking lines and keeping cuts straight if using knives)
- Pencil/marking tool
- Paint brushes
	- You probably want a smaller one for details like the eyes and a larger one for the bigger pieces
- Optional
	- Cutting Mat
